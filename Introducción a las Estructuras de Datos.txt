Introducción a las Estructuras de Datos

Las estructuras de datos son formas de organizar y almacenar información en una computadora para acceder, modificar y gestionar datos de manera eficiente.

Tipos de estructuras de datos
1. Estáticas

No cambian de tamaño durante la ejecución del programa.

Array (arreglo):
Conjunto de elementos del mismo tipo almacenados en posiciones contiguas. Se accede a cada elemento mediante un índice.
Matriz:
Es un arreglo de dos o más dimensiones, útil para representar datos en forma de tabla (filas y columnas).
2. Dinámicas

Pueden cambiar de tamaño durante la ejecución.

a) Lineales

Los elementos están organizados en secuencia.

Lista enlazada:
Conjunto de nodos donde cada uno contiene un dato y una referencia al siguiente nodo.
Pila (Stack):
Estructura que sigue el principio LIFO (Last In, First Out), donde el último elemento en entrar es el primero en salir.
Cola (Queue):
Estructura que sigue el principio FIFO (First In, First Out), donde el primer elemento en entrar es el primero en salir.
b) No lineales

Los elementos no siguen un orden secuencial.

Árbol:
Estructura jerárquica compuesta por nodos, donde existe un nodo raíz y nodos hijos.
Grafo:
Conjunto de nodos (vértices) conectados por enlaces (aristas), que pueden tener dirección o no.
Tabla hash:
Estructura que almacena datos en pares clave-valor y usa una función hash para ubicar rápidamente los datos.
Semana 1:

Concepto de estructura de datos: Se entiende como la forma en que se organizan y almacenan los datos para usarlos eficientemente.

Importancia en la programación: Se explica cómo una buena estructura mejora el rendimiento y la lógica de un programa.

Almacenamiento en computadoras: Se analiza cómo la memoria guarda y gestiona la información.

Tipos de estructuras: Se diferencian las estructuras estáticas, dinámicas lineales y no lineales, viendo sus características generales.



---

Semana 2:

Refuerzo teórico: Se repasan los conceptos básicos para asegurar comprensión sólida.

Aplicación práctica: Se empiezan a resolver ejercicios usando estructuras de datos.

Análisis de problemas: Se aprende a elegir la estructura adecuada según la necesidad del problema.

Ejercicios básicos: Se desarrollan casos simples para afianzar la lógica.



---

Semana 3:

Arreglos unidimensionales: Se introduce esta estructura como una colección de datos del mismo tipo.

Inserción: Cómo agregar elementos en una posición específica.

Eliminación: Cómo quitar elementos sin afectar la estructura.

Actualización: Modificación de valores dentro del arreglo.

Recorrido: Acceso a todos los elementos mediante ciclos.

Copia: Duplicación de arreglos para trabajar con datos similares.



---

Semana 4:

Comparación de arreglos: Evaluar similitudes o diferencias entre estructuras.

Clonación: Crear copias exactas de un arreglo.

Fusión: Unir dos arreglos en uno solo.

Arreglos bidimensionales (matrices): Se introduce el manejo de datos en filas y columnas.

Tipos de matrices: Se estudian matrices como triangulares, simétricas y asimétricas.

Aplicaciones: Uso de matrices en problemas más complejos como cálculos y transformaciones.
